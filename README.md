# Generación 1K Elite — Landing Page

Landing page oficial del programa de acompañamiento 1:1 de juanflopezzz.

## Deploy en Vercel

1. Sube esta carpeta a un repositorio de GitHub
2. Ve a vercel.com y conecta el repositorio
3. Vercel detecta automáticamente el index.html
4. Deploy automático en cada push

## Rutas

- `/` — landing principal (Generación 1K Elite)
- `/programa` — landing del programa premium "De $0 a $1.000 USD · 3 meses" (`programa/index.html`)
